# Portofolio Sahrul Ageng Prasetyo

Portofolio personal yang dibangun dengan Next.js App Router.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser. Untuk build produksi:

```bash
npm run build
npm start
```

## Struktur utama

- `app/page.jsx` — halaman dan interaksi portofolio.
- `app/globals.css` — tampilan responsif, tema terang/gelap, serta animasi.
- `public/assets/img/` — foto profil, gambar proyek, dan sertifikat.

Kontak pada formulir membuka aplikasi email melalui `mailto`; tidak membutuhkan layanan backend.
